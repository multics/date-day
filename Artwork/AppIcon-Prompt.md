# Date Day app icon prompt

Use case: logo-brand

Asset type: macOS 26 application icon for a menu-bar date and weekday utility
named Date Day

Primary request: Create an original, elegant calendar symbol that communicates
both the current day and the passage of time. Use a refined rounded-square macOS
app-icon silhouette. Inside it, show a minimal ivory calendar page with two
subtle binding tabs and one small highlighted day marker, paired with a quiet
arc suggesting a clock or sunrise.

Style/medium: premium Apple-platform app icon; clean geometric forms;
restrained dimensional layering; softly tactile materials; crisp at 16 px;
sophisticated rather than playful

Composition/framing: one centered icon, perfectly balanced, large simple
silhouette, generous internal spacing, no scene or mockup

Color palette: deep midnight indigo and cool blue foundation, warm ivory
calendar surface, one restrained coral-red accent

Lighting/mood: subtle top-left studio light, gentle depth, controlled soft
shadow, calm and precise

Materials/textures: very subtle frosted glass and matte paper; avoid noisy
texture

Constraints: genuinely transparent canvas outside the rounded-square icon
silhouette; no text, no letters, no numbers, no weekday abbreviations, no logos
from existing brands, no watermark; no separate border; no excessive gloss;
the icon must read clearly at menu and Finder sizes

Avoid: generic clip art, busy calendar grids, photorealism, neon colors,
skeuomorphic leather, heavy gradients, extreme 3D perspective
